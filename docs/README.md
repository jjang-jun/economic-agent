# Project Docs

이 폴더는 사람이 읽는 프로젝트 운영 문서의 기준 위치입니다.

- `AGENT_HARNESS.md`: Codex/sub-agent 장기 작업 계약, 검증 루프, 문서 정리 기준
- `CURRENT_STATE.md`: 새 Codex 세션이 먼저 읽는 압축된 현재 상태와 바로 다음 작업
- `future/`: 현재 구현 범위가 아닌 미래 별도 프로젝트 자료
- `future/AI_AGENT_TEAM_BLUEPRINT.md`: 개인 AI 조직 운영체제를 위한 다중 에이전트·Discord·기억·권한·이메일 Draft 설계
- `AGENT_PLATFORM.md`: Discord Agent Server·Gateway worker, 경제 도메인 전문가 `to/cc`, Supabase, GitHub Actions 역할 분리
- `PROGRESS.md`: 상세 개발 이력과 운영 근거; 현재 상태 확인 후 필요한 부분만 조회
- `DISCORD_SETUP.md`: Discord 읽기 전용 리포트 채널, Webhook, 서명 검증 Slash 조회 설정 절차
- `HOME_SERVER.md`: OS 공통 상시 PC worker, 로컬 PostgreSQL/PostgREST, 백업과 단계적 전환 절차
- `REAL_ESTATE_STRATEGY.md`: 2~3년 내 서울·경기 아파트 저점 매수 목표, 공식 데이터·호가·대출·판단 게이트

이전 `memory/`와 `CLAUDE.md`는 현재 운영/AI 참조 기준에서 제외되어 삭제했습니다. 과거 내용은 Git 히스토리에서 확인합니다.
